## 1. 게임 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 탑다운 무한 생존 액션 |
| 플랫폼 | Windows PC |
| 플레이 인원 | 1인 |
| 진행 시간 | 제한 없음. 플레이어 사망 시 종료 |
| 기본 조작 | 상하좌우 이동. 공격은 자동 실행 |
| 공간 구성 | 반복 배경으로 표현하는 무한 필드 |
| 화면 구성 | 타이틀, 플레이, 결과의 3개 Scene |

플레이어는 끊임없이 등장하는 적을 피하며 자동으로 발동하는 무기로 적을 처치한다. 경험치를 획득해 레벨을 올리고, 무기를 선택하고 강화하며 가능한 오래 생존하는 것을 목표로 한다.

시간이 지날수록 적의 능력치와 출현량이 증가한다. 정해진 최종 스테이지나 승리 시점은 없으며, 이동 경로와 무기 선택에 따라 생존 기록이 달라진다.

게임 콘텐츠의 규모를 제한하고, 객체의 생성·갱신·출력·제거와 상속·다형성 등 C#의 객체지향 구조를 실제 기능에 적용하는 데 중점을 둔다. 세부 수치와 미정 항목은 구현 및 플레이 테스트를 통해 확정한다.

## 2. 기본 진행과 화면 구성

1. 타이틀에서 게임을 시작한다.
2. 플레이어는 시작 무기인 마법탄을 보유한 상태로 등장한다.
3. 플레이어는 이동으로 적을 피하고, 보유 무기는 각자의 규칙에 따라 자동 공격한다.
4. 보스를 제외한 적을 처치하면 경험치가 떨어진다.
5. 경험치를 모아 레벨을 올리고 무기 획득 또는 강화 등을 선택한다.
6. 시간이 지날수록 강해지는 적과 주기적으로 등장하는 보스를 상대한다.
7. 체력이 소진되면 결과 화면으로 이동한다.

```text
타이틀 Scene
  ↓ 게임 시작
플레이 Scene
  ├─ 이동 → 자동 공격 → 적 처치 → 경험치 획득
  ├─ 레벨업 → 선택 UI → 전투 재개
  └─ 사망 → 결과 Scene
               ├─ 재시작 → 새로운 플레이
               └─ 타이틀로 돌아가기
```

| 화면 | 주요 구성 |
| --- | --- |
| 타이틀 | 게임 제목, 시작, 종료 메뉴 |
| 플레이 | 배경, 플레이어, 적, 공격 효과, 체력, 경험치, 레벨, 생존 시간, 무기 2칸 |
| 레벨업 UI | 플레이 화면 위에 선택 가능한 보상 표시 |
| 결과 | 생존 기록과 재시작·타이틀 메뉴. 세부 기록 항목은 추후 확정 |

레벨업 UI는 별도 Scene으로 만들지 않고 플레이 Scene 내부 상태로 처리한다. 화면 배치와 선택 키 등 UI 세부 사항은 추후 결정한다.

## 3. 플레이어와 무기 콘텐츠

플레이어의 전투 조작은 이동으로 제한한다. 수동 공격, 대시, 소비 아이템 사용은 두지 않는다. 방향 입력을 조합한 대각선 이동을 지원하되, 대각선과 직선 이동 속도가 같도록 처리한다.

무기는 총 4종이며 동시에 2개까지 보유한다. 마법탄으로 시작하고, 나머지 한 칸은 레벨업 선택으로 획득한다. 별도의 패시브 장비 슬롯은 사용하지 않는다.

| 무기 | 자동 공격 방식 | 특징 |
| --- | --- | --- |
| 마법탄 | 공격 가능한 적 중 가장 가까운 적을 향해 발사 | 발사 시 방향이 결정되는 직선 투사체 |
| 충격파 | 플레이어 주변의 원형 범위를 공격 | 가까이 접근한 여러 적을 동시에 공격 |
| 낙뢰 | 공격 가능한 적 중 무작위 대상을 선택 | 선택한 대상에게 피해와 이펙트 적용 |
| 관통탄 | 플레이어의 마지막 이동 방향으로 발사 | 이동 경로상의 여러 적을 관통 |

무기별 공격 간격·공격력·범위·최대 레벨은 별도 수치로 관리하며 테스트 후 확정한다. 이동 이력이 없을 때의 관통탄 방향과 관통 대상 수·투사체 수명도 구현 전에 결정한다.

## 4. 적

적은 행동에 따라 총 4종으로 구성하며, 각 종류에 하나의 디자인과 애니메이션 리소스 세트를 제작한다. 능력치 증가를 위해 별도의 외형 종류를 추가하지 않는다.

| 종류 | 속도 | 생성과 행동 | 처치 보상 |
| --- | --- | --- | --- |
| 일반적 | 보통 | 카메라 밖 일정 거리 범위에서 무작위 개별 생성 후 플레이어 추적 | 경험치 |
| 횡단적 | 빠름 | 화면 밖에서 무리로 생성 후 정해진 한 방향으로 횡단 | 경험치 |
| 포위적 | 매우 느림 | 플레이어 주변의 화면 밖 원 둘레에 생성 후 각 개체가 플레이어 추적 | 경험치 |
| 보스 | 느림 | 화면 밖에서 주기적으로 생성되어 플레이어 추적. 높은 체력 보유 | 레벨업 1회 보상 |

포위적은 생성 당시에는 원형 배치를 이루지만, 이동 목표는 플레이어의 현재 위치이다. 따라서 플레이어가 이동하면 원형이 흐트러질 수 있으며, 플레이어가 멀리 이동하면 추격이 어려워진다.

적의 이동 애니메이션과 공용 피격·사망 효과를 활용해 행동과 피해 여부를 표현한다. 구체적인 외형과 프레임 수는 리소스 제작 시 결정한다.

## 5. 좌표·이동·카메라 시스템

### 5.1 월드 좌표와 화면 좌표

플레이어·적·투사체·경험치는 모두 월드 좌표를 가진다. 이동과 충돌은 월드 좌표로 계산하고, 출력할 때 화면 좌표로 변환한다.

```text
화면 좌표 = 객체의 월드 좌표 - 카메라의 월드 좌표 + 화면 중앙
카메라의 월드 좌표 = 플레이어의 월드 좌표
```

카메라는 지연 없이 플레이어를 따라가므로 플레이어는 화면 중앙에 표시된다. 플레이어가 움직일 때 다른 객체의 월드 좌표를 일괄 수정하지 않는다.

### 5.2 이동과 배경

- 이동량은 이동 방향, 속도, 경과 시간으로 계산한다.
- 방향 벡터를 정규화해 대각선 이동 속도를 일정하게 유지한다.
- 배경은 카메라 위치에 따라 필요한 타일만 반복 출력한다.
- 화면 밖 객체는 출력을 생략할 수 있지만, 이동·생성·제거 판단은 별도로 수행한다.
- 배경 장애물과 통행 제한의 도입 여부는 미정이며, 기본 이동 검증은 장애물 없는 필드에서 진행한다.

## 6. 전투·충돌 시스템

### 6.1 공격 실행

각 무기는 독립적인 공격 타이머를 가진다. 공격 간격이 지나면 해당 무기의 대상 선정과 공격 함수를 실행한다. 자동 조준의 탐색 범위는 무기 설정으로 분리한다.

마법탄과 낙뢰처럼 대상이 필요한 무기는 대상이 없으면 공격을 보류한다. 관통탄은 마지막 이동 방향을 사용하고, 충격파는 플레이어의 현재 위치를 중심으로 판정한다.

공격 생성과 피해 판정을 분리하여, 투사체가 이동한 뒤 충돌로 피해를 주는 공격과 즉시 범위·대상에 피해를 주는 공격을 함께 지원한다.

### 6.2 충돌과 피해

기본 충돌은 원형 범위의 겹침으로 처리하는 설계안을 사용한다. 두 객체의 중심 거리와 반지름 합을 비교하며, 이미지 전체를 충돌 영역으로 사용할 필요는 없다.

| 판정 대상 | 처리 |
| --- | --- |
| 플레이어 ↔ 적 | 접촉 피해 처리 |
| 공격 ↔ 적 | 무기 규칙에 따른 피해 처리 |
| 플레이어 ↔ 경험치 | 고정 획득 반경 안에서 경험치 획득 |

피해를 받은 객체는 체력을 감소시키고, 체력이 0 이하이면 사망을 처리한다. 방어력과 치명타 시스템은 구현 범위에서 제외한다.

동일한 공격이 여러 프레임에 걸쳐 겹치더라도 의도하지 않은 연속 피해가 발생하지 않도록 한다. 단발 범위 공격은 발동당 대상별 1회, 관통탄은 투사체별 동일 대상 1회를 기본 설계안으로 둔다.

접촉 피해 간격, 피격 무적 시간, 넉백과 적끼리의 밀어내기 여부는 추후 확정한다. 사망 처리는 한 번만 실행하여 경험치와 처치 기록이 중복 지급되지 않도록 한다.

## 7. 경험치·성장·장비 시스템

### 7.1 경험치 획득

보스를 제외한 적은 처치 위치에 경험치를 떨어뜨린다. 경험치 획득 반경은 고정이며 장비나 성장에 의해 증가시키지 않는다.

레벨이 높아질수록 다음 레벨에 필요한 경험치가 증가한다. 초반에는 완만하게 증가하고 후반으로 갈수록 증가 폭이 커지는 함수를 사용한다. 구체적인 공식과 수치는 플레이 테스트로 결정한다.

레벨업에 사용하고 남은 경험치는 유지한다. 한 번에 여러 레벨이 상승하면 선택을 순서대로 처리한다.

### 7.2 레벨업 선택

레벨업 시 전투를 일시 정지하고 선택 UI를 표시한다. 선택 중에는 이동·공격·적 출현·생존 시간이 진행되지 않으며, UI 입력은 유지한다.

| 상태 | 선택 가능한 보상 |
| --- | --- |
| 무기 슬롯에 여유가 있음 | 새로운 무기 획득, 보유 무기 강화, 체력 회복 |
| 무기 슬롯이 가득 참 | 보유 무기 강화, 체력 회복 |
| 장착 무기가 모두 최대 레벨 | 체력 회복 또는 전체 무기 피해 배율 +5%p |

최대 3개의 유효한 선택지를 중복 없이 표시하는 구성을 기본으로 한다. 선택 가능한 후보가 적으면 실제 후보 수만 표시한다. 최대 레벨 무기는 일반 강화 후보에서 제외한다.

후반 피해 배율 증가는 100% → 105% → 110%처럼 합산하며, 이번 플레이에만 적용한다. 새 게임을 시작하면 초기화한다. 회복량과 최대 체력 상태에서의 회복 선택지 처리 방식은 추후 결정한다.

### 7.3 무기 보유 정보

장비 목록은 무기 2칸과 각 무기의 종류·레벨을 관리한다. 별도의 아이템 보관함이나 패시브 슬롯은 두지 않는다. 신규 획득은 빈 슬롯에 등록하고, 보유 무기 강화는 해당 무기의 성능 정보를 갱신한다.

무기 교체·버리기와 저장 기능의 도입 여부는 별도로 결정하며, 현재 기초 기획의 필수 기능으로 포함하지 않는다.

## 8. 적 출현·난이도·보상 시스템

### 8.1 출현 위치와 주기

종류별 출현 시점은 주기로 관리하고, 위치와 진입 방향은 무작위로 결정한다.

- 일반적: 카메라 사각 영역을 바깥으로 확장한 범위 중 화면 밖 부분에서 위치를 선택한다.
- 횡단적: 화면 밖 한쪽에서 무리를 생성한다. 화면을 가로지르는 이동 방향을 생성 시 정하고 유지한다.
- 포위적: 플레이어에서 화면 모서리까지의 거리보다 큰 반지름을 사용해 원 둘레에 일정 간격으로 배치한다.
- 보스: 별도의 출현 주기에 따라 카메라 밖에서 생성한다. 정확한 주기는 추후 결정한다.

일반적은 지속적으로 등장하며, 횡단적·포위적·보스는 주기적인 압박을 제공한다. 생성 거리·무리 크기·출현 간격은 조정 가능한 값으로 분리한다.

### 8.2 난이도 증가

생존 시간이 길어질수록 새로 생성되는 적의 능력치와 출현량을 증가시킨다. 속도 차이는 각 종류의 행동을 구분하는 기준으로 유지한다.

동시 적 수와 최소 생성 간격에 상한·하한을 두어 객체 수가 무제한 증가하지 않도록 한다. 제한 도달 시의 생성 생략 방식과 보스 동시 등장 수는 구현 전에 확정한다.

### 8.3 처치와 거리 제거

처치된 일반적·횡단적·포위적은 경험치를 지급한다. 보스는 별도 보상을 지급하되 보상 내용은 미정이다.

플레이어에게서 지나치게 멀어진 적의 제거를 적용해 성능을 관리한다. 거리 제거는 처치와 구분하여 경험치·보상·처치 기록을 지급하지 않는다. 보스의 거리 제거 예외 여부와 기준 거리는 추후 결정한다.

## 9. 프로그램 구조와 객체 실행 흐름

### 9.1 설계 방향

glc의 창·입력·출력·시간 기능 위에 게임 객체 관리 구조를 구성한다. 객체가 Transform을 가지고 공통 실행 흐름에 참여하도록 하되, 게임에 필요한 범위의 단순한 구조를 목표로 한다.

아래는 주요 책임을 정리한 설계안이다. 범용 컴포넌트 부착 방식과 GameObject 상속 중심 방식 중 구체적인 구성은 구현 전에 확정한다.

| 객체·기능 | 역할 |
| --- | --- |
| `GameMain` | glc 실행 흐름 연결, Scene 전환 |
| `GameManager` | 싱글톤으로 게임 상태, 생존 시간, 처치 기록 관리 |
| `Scene` | 객체 목록과 생성·제거 요청 관리 |
| `TitleScene` / `GameplayScene` / `ResultScene` | 화면별 입력과 진행 처리 |
| `GameObject` | 활성 상태, Transform, 공통 실행 함수 |
| `Transform` | 월드 위치, 회전, 스케일 |
| `Player` | 이동 입력, 체력, 경험치, 보유 무기 |
| `Enemy`와 적 4종 | 공통 피해·사망 처리와 종류별 이동 |
| `Weapon`과 무기 4종 | 공격 주기, 대상 선정, 발사·범위 공격 |
| 렌더링·애니메이션 기능 | 이미지 출력, 프레임 전환, 출력 순서 |
| 충돌 처리 기능 | 원형 판정과 피해·획득 전달 |
| 생성·풀링 기능 | 적 생성 주기와 반복 객체 재사용 |

### 9.2 갱신과 출력

한 프레임의 기본 흐름은 다음과 같다.

```text
입력 확인
  → 현재 게임 상태 확인
  → 객체의 행동·이동·공격 갱신
  → 충돌·피해·경험치 획득 처리
  → 생성·제거 예약 반영
  → 카메라 위치 갱신
  → 월드 객체 출력
  → UI 출력
```

프레임 경과 시간을 전달해 이동과 공격·애니메이션 타이머를 갱신한다. 고정 간격 갱신을 추가하는 경우에는 일반 갱신과의 역할을 분리하며, `FixedUpdate` 채택 여부는 미정으로 둔다.

초기화는 최초 생성 시의 준비와 실제 게임 참여 시의 준비로 구분한다. `Awake`·`Start` 등의 함수명과 세부 호출 순서는 구조 확정 시 결정한다. 풀 재사용 초기화는 최초 초기화와 구분한다.

출력은 배경 → 바닥 보상 → 플레이어·적 → 공격·이펙트 → UI 순서를 기본으로 한다. 객체별 출력 레이어와 순서 값을 관리하며, 렌더링 함수에서는 게임 상태를 변경하지 않는다.

### 9.3 객체별 역할과 상호작용

`GameManager`는 싱글톤 패턴으로 구성하여 프로그램 실행 중 하나의 인스턴스를 유지한다. 각 Scene은 같은 `GameManager`를 통해 게임 상태와 진행 기록을 확인한다. 게임 시작·레벨업 선택·전투 재개·사망에 따른 상태 변경을 관리하며, `GameMain`은 그 상태에 맞춰 Scene을 전환한다.

생존 시간은 전투가 진행되는 동안에만 증가하고, 사망 시에는 기록을 확정해 결과 Scene에 전달한다. 새 게임을 시작하면 같은 인스턴스에서 이전 플레이의 진행 기록을 초기화한다. 개별 객체의 이동·공격과 생성·제거는 각 객체와 Scene이 담당한다.

적은 `Enemy`를 상속해 체력과 피해·사망 처리를 공유하고, 이동 함수는 종류에 따라 재정의한다. 일반적과 보스의 추적 계산은 함께 사용하되 속도·체력·보상으로 차이를 둔다. Scene은 적을 공통 목록으로 관리하며, 각 적의 이동 방식과 관계없이 동일한 갱신 함수를 호출한다.

무기는 `Weapon`에서 공격 주기와 레벨을 관리하고, 각 무기가 대상 선정과 공격 방식을 구현한다. 플레이어는 보유 무기의 갱신을 요청하며, 마법탄 발사나 충격파의 범위 판정은 해당 무기에서 처리한다.

충돌 처리에서는 피해를 받을 수 있는 대상에 `IDamageable`을 통해 피해를 전달한다. 체력 감소와 사망 여부는 대상 객체가 판단하며, 외부에서 체력 값을 직접 변경하지 않는다. 경험치와 무기 레벨도 획득·강화 메서드를 통해 변경하여 레벨업 조건과 강화 제한을 함께 확인한다.

체력·경험치 변경과 사망은 이벤트로 전달한다. UI는 변경된 값을 화면에 반영하고, `GameManager`는 적 처치 알림을 받아 처치 수를 갱신한다. 레벨업 선택지는 보유 무기와 슬롯 상태를 기준으로 후보를 걸러 구성한다.

## 10. 객체 수명과 성능 관리

- 객체 목록 순회 중 직접 추가·삭제하지 않고 요청을 예약해 정해진 시점에 반영한다.
- 사망한 객체는 이후 충돌·공격 대상에서 즉시 제외하고, 목록 제거 또는 풀 반환은 안전한 시점에 수행한다.
- 적·투사체 등 반복 생성되는 객체는 풀링 적용 대상으로 검토한다.
- 재사용 시 체력, 위치, 이동 방향, 공격 타이머, 애니메이션과 피격 이력을 초기화한다.
- 풀링과 충돌 검사 비용은 구분한다. 먼저 동시 객체 수를 제한하고 실제 성능을 측정한다.
- 적끼리의 모든 조합을 검사하지 않고 플레이어·공격·획득 대상처럼 필요한 조합만 판정한다.
- 경험치 보석의 무한 누적에 대비해 개수 제한 또는 값 합산 방식을 결정한다.
- 새 게임에서는 이전 객체·타이머·경험치·무기·피해 배율이 남지 않도록 초기화한다.
- Scene과 프로그램 종료 시 이미지·사운드 자원의 소유 관계에 따라 해제한다.

## 11. 리소스 구성

적 외형은 총 4종으로 제한하고 각 외형의 프레임을 스프라이트 시트로 구성한다. 피해 깜빡임과 공용 효과를 활용하여 추가 리소스 제작량을 줄인다. 무기 강화에는 기존 이미지를 재사용한다.

```text
resource/
├─ image/
│  ├─ player/          # 플레이어
│  ├─ enemy/           # 일반적, 횡단적, 포위적, 보스
│  ├─ weapon/          # 무기 아이콘과 투사체
│  ├─ effect/          # 충격파, 낙뢰, 공용 피격·사망 효과
│  ├─ pickup/          # 경험치 및 확정된 보상
│  ├─ background/      # 반복 배경
│  └─ ui/              # 메뉴, 체력·경험치 표시, 선택창
└─ audio/
   ├─ bgm/             # 배경 음악
   └─ effect/          # 공격, 피격, 획득, 레벨업, 메뉴 효과음
```

애니메이션 시간은 게임 진행 시간과 연결해 레벨업 선택 중 전투 애니메이션도 함께 정지하도록 한다. UI 애니메이션이 필요한 경우에는 전투 정지와 분리한다.
